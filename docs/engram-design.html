Design Sheet · Local Temporal Memory Engine · Rev D

Engram

A single-binary, fully local memory system for coding agents. One temporal knowledge graph holds code structure, project decisions, and user preferences — facts are never deleted, only superseded, with the reasoning path preserved.

C# · Native AOTSQLite + FTS5 + vecMCP over stdioClaude Code hooksZero services
Prime directive
Tokens the LLM did not have to load.
Memory substitutes for context. Recall → use → amend → re-store; discovery is the fallback learning path, and its findings are written back.
Zone A

System Architecture

One AOT binary, three entry modes: CLI command, fast-exit hook, session-scoped MCP server. SQLite WAL coordinates all concurrent access — no daemon, no lock server.

agent trafficinternal
Zone B

One Database · One Memory Tree

A single SQLite file holds the whole memory tree. Every fact lives on a rooted path from broad to specific — the path is the storage key, a retrieval lane, and the agent's structured way to recall by category. Deleting a repo on disk deletes nothing here. Copy ~/.engram to move machines.

engram_browse(path) → table of contents, never a dump

Recall narrows with path_prefix; cross-cutting questions omit it. Auto-routing files new facts by kind + context (preferences → /people/jim/…, repo learnings → /code/<repo>/…); an explicit path always wins.

Zone C · Signature Detail

Temporal Supersession Chain

Facts are append-only. A revision closes the old fact (valid_to, superseded_by) and records why in the supersession table. Current-state queries read only the live head; the whole belief path stays one expand(id, history) away.

live fact (valid_to = NULL) superseded fact — kept forever contradictions stored + flagged ⚠ until revised
Zone D

Context-Frugal Recall

Three lanes seed, the graph expands, fusion ranks, packing enforces the budget. Output is distilled statements with handles — never raw source. A gaps line names what memory doesn't know, steering the agent to discover and remember().

1
Seed
FTS5 BM25 · vec KNN · entity match — live facts, optional path_prefix
2
Expand
Graph walk ≤ 2 hops from seed subjects; edge weight × relation prior
3
Fuse
Reciprocal Rank Fusion × salience × scope prior (repo vs global context)
4
Pack
Dedupe by subject+predicate; truncate to budget (default 500 tokens)
5
Reinforce
Bump access counts → salience; log recall to session provenance
