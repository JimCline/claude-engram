tool: engram_browse
List what Engram's memory holds under a path — children, fact counts, and the top facts at that node. A table of contents, not a search: engram_recall finds facts by content, this shows how an area is organised. Paths look like /people/jim or /projects/acme.
  param: path
  The memory path to list, e.g. /projects/acme.
  param: depth
  Levels of children to show, 1-3. Defaults to 1.

tool: engram_expand
The full story behind one fact handle: its supersession history, related facts on the same subject, its evidence, or where it was learned. Call it when a fact engram_recall returned needs scrutiny before you rely on it. The details view returns everything the handle holds, paged by budget_tokens and offset.
  param: id
  The bracketed fact id, e.g. "f42".
  param: view
  One of: history, related, evidence, source, details.
  param: budget_tokens
  Maximum tokens returned per call. Defaults to 800.
  param: offset
  Character offset to continue a paged details view from. Defaults to 0.

tool: engram_forget
Retract a stored fact by its bracketed id (e.g. "f42"). Use it whenever the user says something stored is wrong, private, or no longer true, and to clear a session note that turned out to be mistaken. Retracted facts stop appearing in recall immediately, and stay retracted — nothing re-seeds them. Call engram_recall first if you need to find the id.
  param: id
  The bracketed id of the fact to retract, e.g. "f42".

tool: engram_index_repo
Record the user's answer on indexing this checkout: enroll, decline (stop asking), or later (ask in a week). Call as soon as they answer — decline is as valid an answer as enroll.
  param: path
  Git checkout path.
  param: decision
  enroll, decline, or later.

tool: engram_judge
Record a verdict on how two facts relate: supersedes, conflicts_with, scoped, or not_conflict. Call it after engram_recall or engram_expand surfaces two facts that might disagree, to settle which one stands and why. The verdict is recorded alongside both facts — neither is changed or closed by it — and shows up under engram_expand ... history for either one.
  param: fact_id
  The bracketed id of the fact being judged, e.g. "f42".
  param: related_id
  The bracketed id of the fact it is being compared against, e.g. "f17".
  param: relation
  One of: supersedes, conflicts_with, scoped, not_conflict.
  param: reason
  Why this verdict — what distinguishes or reconciles the two facts.

tool: engram_navigate
Where is a symbol defined, what does a file import, who calls/is called by a symbol, what does a type inherit/implement or who implements it, or what members a type declares — a deterministic lookup over indexed code, not a search. Use it instead of Read/Grep to answer 'where is Z defined', 'what does Y import', 'who calls Z', 'what does Z call', 'what does Z implement', 'who implements Z', or 'what members does Z have'. relation is defined_at, imports, callers, callees, implements, implementers, or members.
  param: query
  A symbol name for defined_at/callers/callees/implements/implementers/members, or a file path for imports.
  param: relation
  One of: defined_at, imports, callers, callees, implements, implementers, members.
  param: repo
  Restrict matches to one repo's indexed code, by its slug.
  param: limit
  Maximum matches returned. Defaults to 20, clamped to 1-100.

tool: engram_pin
Pin a fact for this session: engram_recall guarantees it top position whenever the query matches it, without pulling it into results it would not otherwise match. Use it to keep a fact from being crowded out of the digest for the rest of a task where it keeps mattering. The pin does not persist past this session — engram_unpin releases it early.
  param: fact_id
  The bracketed id of the fact to pin, e.g. "f42".

tool: engram_recall
Check Engram's memory BEFORE reading files or exploring the repo. Searches Engram's stored facts (decisions, conventions, gotchas, contracts) and returns a token-budgeted, ranked digest with fact handles and a coverage estimate. Call this first for any question about how this project works, what was decided, or why something is the way it is — it is far cheaper than rediscovering the answer by reading source.
  param: query
  What you want to know, as a few keywords or a short question.
  param: budget_tokens
  Maximum tokens to spend on the response. Defaults to 500.

tool: engram_remember
Engram's durable memory, and where anything worth keeping goes even when another memory system is available. Call it when the user asks you to remember or save something, and whenever you learn something durable: a decision, a constraint, a partial result, a dead end already ruled out — state you would otherwise repeat in context and would lose to compaction. `engram_recall` ranks these above long-term memory for the rest of this session, and they stay recallable in later ones, so this is for anything still true next week rather than only the next ten minutes. Subagents pass their own name in `agent`. When restating something the user just said, pass the bracketed id of its automatic capture in `supersedes` so the rewrite replaces it rather than duplicating it. When candidates are enabled, also returns up to 3 similar live facts already stored, for a follow-up engram_judge call.
  param: statement
  The fact to remember, as a short, self-contained statement — aim under ~300 characters; depth belongs in details.
  param: details
  Depth the statement cannot carry — a full config, a long rationale, verbatim output. Most memories need none: if the statement holds it, stop there.
  param: subject
  What or who the fact is about, if not obvious from the statement.
  param: evidence
  Where this was learned — a file path, PR, or command output.
  param: agent
  Your own name, if you are a subagent recording this fact rather than the main agent.
  param: supersedes
  The bracketed id of a raw user-statement capture this restates, e.g. "f42". Closes that capture so the rewritten version replaces it instead of duplicating it.
  param: sync
  Flags for sync. Triggered by "share engram" plus content.
  param: review_after
  When to revisit this: a relative duration ('3d', '2w', '12h') or an ISO date. Surfaces in 'engram review list' and doctor once it passes.

tool: engram_revise
Replace a stored belief with a corrected statement, recording why. The old fact is closed, never erased, and the new one takes its place in recall. Use it when the user or fresh evidence contradicts something stored; engram_forget retracts without a replacement.
  param: fact_id
  The bracketed id of the fact to revise, e.g. "f42".
  param: statement
  The corrected statement, short and self-contained.
  param: reason
  Why the belief changed.
  param: evidence
  Where the correction came from — a file, PR, or the user's words.
  param: details
  Depth for the corrected fact. Does not carry forward from the old version — restate it or drop it deliberately.
  param: sync
  Sync flag; omit inherits, else overrides.
  param: review_after
  When to revisit this: a relative duration ('3d', '2w', '12h') or an ISO date. Does not carry forward from the old version.

tool: engram_unpin
Release a fact pinned earlier this session with engram_pin. Pins that are never released end with the session anyway.
  param: fact_id
  The bracketed id of the fact to unpin, e.g. "f42".
